# Jermaine's Hub

A comprehensive knowledge base and blog built with [MkDocs](https://www.mkdocs.org/) and [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/). This repository contains university course notes, financial market analysis, and personal learning resources.

**Live Site:** [https://JermaineChen404.github.io](https://JermaineChen404.github.io)

---

## 📚 Contents

This repository contains:

- **University Course Notes** - Comprehensive study materials from Hong Kong University of Science and Technology courses
- **Market Analysis** - Financial market insights and analysis
- **Personal Learning Resources** - Research and learning materials across various topics

Navigate to the [live site](https://JermaineChen404.github.io) to explore all available content organized by subject and topic.

---

## 🛠️ Technology Stack

- **Static Site Generator:** [MkDocs](https://www.mkdocs.org/)
- **Theme:** [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)
- **Math Rendering:** [KaTeX](https://katex.org/)
- **Diagrams:** [Mermaid](https://mermaid.js.org/)
- **Hosting:** [GitHub Pages](https://pages.github.com/)
- **CI/CD:** GitHub Actions

## 📝 Project Structure

```
.

│   ├── [subject-folders]/         # Organized by subject/course
│   └── javascripts/               # Custom JavaScript
├── mkdocs.yml                     # MkDocs configuration
├── custom_theme/                  # Custom theme overrides
├── .github/workflows/             # GitHub Actions for CI/CD

```
